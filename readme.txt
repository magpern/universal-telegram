Foundation milestone for the Telegram Operations Hub. No end-user functionality ships in this release.

== Description ==

This release establishes the plugin's architecture, security boundaries, privacy model, and testing
infrastructure. It ships no Telegram connectivity, event capture, conversation, chat widget, or AI
functionality; those arrive in later milestones.
